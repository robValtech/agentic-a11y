# Confidence Scoring Guidelines

This document defines how confidence scores must be interpreted and assigned for both:

- HTML element detection
- WCAG issue detection

Confidence values range from **0.0 to 1.0** and represent the certainty of the model's inference based on visual evidence.

---

## Levels

### ✅ 0.90 – 1.00 (Very High Confidence)

- Element or issue is clearly visible and unambiguous
- Strong visual and semantic cues
- Little to no interpretation required

**Examples:**

- Clearly labeled button with standard styling
- Obvious color contrast failure
- Clearly structured navigation bar

---

### ✅ 0.75 – 0.89 (High Confidence)

- Element or issue is clear but with minor ambiguity
- Small amount of inference required

**Examples:**

- Icon + text that strongly suggests a button
- Clearly grouped UI section with minor ambiguity in role

---

### ✅ 0.60 – 0.74 (Moderate Confidence)

- Element or issue inferred from context
- Semantic meaning not fully explicit

**Examples:**

- Icon-only control assumed to be interactive
- Section inferred as a semantic region without explicit boundaries

---

### ⚠️ 0.40 – 0.59 (Low Confidence)

- Weak or ambiguous visual signals
- Multiple valid interpretations possible

**Examples:**

- Decorative vs interactive icon ambiguity
- Unclear grouping or layout intent

---

### ❗ 0.00 – 0.39 (Very Low Confidence)

- Minimal or highly uncertain evidence
- Detection is speculative

**Examples:**

- Guessing structure in minimal UI fragments
- Inferring landmarks without clear boundaries

---

## Critical Rules

### ✅ Element Confidence

- Must reflect:
  - Visual clarity
  - Structural cues
  - Semantic certainty

---

### ✅ Issue Confidence

- Must reflect:
  - Strength of observable evidence
  - Certainty of WCAG violation
  - Accuracy of mapping to WCAG criteria

---

### 🚨 Low Confidence Handling

- Issues with confidence < **0.60**:
  - MUST NOT be attached to elements
  - MUST be placed in the `flags` array

---

## General Guidelines

- Be conservative with confidence scores
- Prefer underestimation over overconfidence
- Do not assign high confidence without strong visual evidence
- Confidence must always be justified in the `reason` field

# Accessibility Issue Severity Levels

This document defines severity classifications used to prioritise accessibility issues identified during UI analysis.

Severity levels do NOT replace WCAG conformance levels (A, AA, AAA). Instead, they represent the **impact of an issue on users** and help guide prioritisation.

---

## Critical

### Definition

An issue that prevents users from completing essential tasks or accessing core functionality.

### Characteristics

- Blocks interaction or navigation
- Makes content or functionality inaccessible
- Affects key user journeys

### Examples

- Button or link not accessible to screen readers (WCAG 4.1.2)
- Form inputs without labels (WCAG 1.3.1 / 3.3.2)
- Keyboard trap preventing navigation (WCAG 2.1.2)
- Essential content not readable or operable

---

## High

### Definition

An issue that significantly impacts usability or comprehension for users with disabilities.

### Characteristics

- Causes major difficulty in interaction or understanding
- Requires workaround or increased effort
- Affects important but not blocking functionality

### Examples

- Insufficient color contrast for primary text (WCAG 1.4.3)
- Missing focus indicators (WCAG 2.4.7)
- Incorrect semantic roles affecting navigation
- Interactive elements not clearly distinguishable

---

## Medium

### Definition

An issue that creates noticeable difficulty but does not prevent task completion.

### Characteristics

- Reduces usability or clarity
- Causes friction but does not block access
- Affects secondary interactions or structure

### Examples

- Poor heading structure (WCAG 1.3.1)
- Ambiguous link or button labels
- Suboptimal touch target size
- Mild layout complexity affecting comprehension

---

## Low

### Definition

A minor issue with limited impact on usability or accessibility.

### Characteristics

- Cosmetic or low-impact
- Does not significantly affect task completion
- May affect best practices or polish

### Examples

- Minor spacing or grouping inconsistencies
- Slightly suboptimal contrast where still readable
- Redundant or overly verbose labels
- Decorative elements not optimally handled

---

## Key Principles

### Severity ≠ WCAG Level

- WCAG level (A / AA / AAA) indicates **compliance requirement**
- Severity indicates **real-world user impact**

A WCAG AA issue can be:

- Critical ✅
- High ✅
- Medium ✅

---

### Severity Should Be User-Centred

Severity must reflect:

- Impact on real users
- Task completion difficulty
- Access to information or functionality

---

### Prefer Conservative Classification

When uncertain:

- Choose the lower severity unless impact is clearly severe
- Avoid inflating severity without strong evidence
